# Simple Pixelbot for Roblox Death Penalty Showdown minigame
- Simple Pixelbot created for the Roblox game "Death Penalty", and its minigame "Showdown".

- This Pixelbot works by having the user adjust their in-game camera, such that the top-middle is focused on the minigame's Lamp.
- The Lamp, being initially Red in color, goes from it's color to a Green color, signifying that the in-game duel has now begun.
- Upon turning Green, the primary logic of the Pixelbot begins, where a server debounce check is performed quickly, and then
- the Windows API is used to simulate mouse clicking.

- The user simply needs to hover their top-middle pixel over the minigames in-game lamp, and hover their cursor over the opposing duelist for the Pixelbot to work as intended.
  
- This program is intended for *1920x1080* Monitor screen sizes, and I do fully acknowledge that these numbers can be quickly adjusted to allow
- for more dynamic screen size checking. The plus side is that the source is fairly simple and hackable with documentation, and this can be
- added with minimal adjusting.

- Intended to be compiled for either x86/x86_64 systems

- Thank you for reading! I hope you enjoy this project.
